# 🎵 MusicStats

**MusicStats** — это *лёгкое* консольное приложение для анализа музыкальной библиотеки. Поддерживает **фильтрацию по жанрам**, **топы треков и исполнителей** и **статистику по годам и странам**.

## Возможности

- Фильтрация треков по **жанру**, **году** и **длительности**
- Подсчёт **общей и средней длительности** библиотеки
- Топ-N треков по **прослушиваниям**
- Топ-N **исполнителей** по суммарным прослушиваниям
- Распределение по **жанрам**, **годам** и **странам**
- Расчёт **соотношения лайков к прослушиваниям**
- Опция **исключения explicit-треков**

## Установка

1. Установите Python 3.10+
2. Клонируйте репозиторий
3. Установите зависимости

```bash
git clone https://github.com/user/musicstats.git
cd musicstats
pip install -r requirements.txt
```

## Использование

```bash
musicstats analyze library.json --genre rock --year-from 2015 --top 5
musicstats top-artists library.json --top 10
musicstats ratio library.json --include-explicit false
```

| Команда | Описание |
|---|---|
| `analyze` | Полный анализ библиотеки |
| `top-artists` | Топ исполнителей по прослушиваниям |
| `top-tracks` | Топ треков по прослушиваниям |
| `ratio` | Среднее соотношение лайков/прослушиваний |

## Архитектура

> MusicStats построен по принципу **чистых функций**: анализ не мутирует входные данные и не зависит от внешнего состояния. Это упрощает тестирование и повторное использование.[^1]

```
+-------------------+
|   CLI (argparse)  |
+---------+---------+
          |
          v
+-------------------+
| analyze_tracks()  |
+---------+---------+
          |
          v
+-------------------+
|  statistics /     |
|  collections      |
+-------------------+
```

> > Вложенная цитата: «Простота — залог надёжности».

[^1]: Все вычисления выполняются только средствами стандартной библиотеки Python.
